# Sneaker Hub

Приложение магазина кроссовок на Flutter. Работает на Android, iOS и в браузере.

Проект сделан на основе открытого UI-шаблона [FlutterShop](https://github.com/abuanwar072/E-commerce-Complete-Flutter-UI): каталог переведён на кроссовки, второстепенные разделы убраны, экраны-заглушки заменены рабочими.

## Возможности

- Онбординг из пяти слайдов, вход и регистрация с валидацией полей
- Главная с каруселью акций, категориями, блоками «Popular sneakers», «Flash sale» и «Best sellers»
- Каталог по категориям (Sneakers, Sport, Kids, Care & laces)
- Поиск по названию и бренду
- Карточка товара: галерея, характеристики, доставка, возврат, отзывы, похожие модели
- Выбор размера и цвета, покупка в один шаг
- Корзина с изменением количества и пересчётом суммы
- Закладки и профиль

## Запуск

Нужен Flutter 3.x и JDK 17 для сборки под Android.

```bash
flutter pub get
flutter run -d chrome        # в браузере
flutter run                  # на подключённом устройстве или эмуляторе
```

Если Android-сборка падает с ошибкой `Unsupported class file major version`, укажите Flutter версию Java 17:

```bash
flutter config --jdk-dir=$(/usr/libexec/java_home -v 17)
```

## Структура проекта

```
lib/
├── main.dart          — точка входа, тема и стартовый маршрут
├── entry_point.dart   — каркас с нижней навигацией из пяти вкладок
├── constants.dart     — цвета, отступы, валидаторы форм
├── route/             — имена маршрутов и роутер (один switch на всё приложение)
├── models/            — ProductModel, CategoryModel и демо-каталог
├── components/        — переиспользуемые виджеты: карточки, баннеры, скелетоны
├── theme/             — тема, типографика, стили полей и кнопок
└── screens/           — по папке на раздел, внутри views/ и views/components/
```

Данные пока демонстрационные: каталог задан списками в `lib/models/product_model.dart`,
фотографии лежат в `assets/images/products/`. Чтобы подключить бэкенд, достаточно
заменить эти списки на ответ API — экраны менять не придётся.

## Тесты

```bash
flutter test
```

`test/smoke_test.dart` прогоняет все экраны, переключает вкладки и проверяет поиск и корзину.
